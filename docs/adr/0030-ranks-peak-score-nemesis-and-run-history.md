# 0030 战绩做得像回事：段位、巅峰分、宿敌与留底（v3.8）

## 背景

用户 2026-11-11 看完 v3.7 的战绩页：

> 「战绩页你不是说和以前的自己比较、段位、复仇吗，在哪里，还有战绩页可以加上一些最近做测试的记录和正确率」

这条确实欠着——v3.7 只把「此刻大概能想起几个词」和战斗力做出来了，段位、历史比较、复仇在当时讨论过、没落地。
同一轮里用户把称号名定死（入门 白词·青词·蓝词·绿词·橙词·紫词 → 进阶 赤段·玄段·金段 → 顶级 词圣），
并说「其它没问题，不用给我草图了，直接做吧」。那一批界面意见（近况卡并成一张、词库导入收纳、设置页折叠、
室友入口改小）也在这一刀一起做完。

一条前提先说清楚：**这一刀只跟你自己比**。不做排行榜、不做对战、不上传任何数据；影子对战与每周联赛另刀再谈。

## 决定

### 1. Room v18：两张新表，都是给人看的账，不碰调度

- `quiz_runs`——每做完一组留一行（`mode / finishedAtSec / asked / correct / wrong / bestStreak`，
  `finishedAtSec` 建索引）。会话表 `quiz_session` 在结束时整行删掉，不留底就没人知道自己破过什么纪录。
- `recall_snapshots`——一天一行（`epochDay` 主键 + `canRecall / mastered / atSec`），**只往更高写**
  （`insertIfAbsent` 占位，再 `raiseBest` 抬高）。「此刻能想起几个词」是卡片当下状态的函数，
  明天再也回推不出今天的样子，所以必须当天落一笔。
- `MIGRATION_17_18` 只建两张空表；`QuizRunMigrationTest` 覆盖 v17→v18（旧数据一字不动）、
  一天只留最高点、v1→v18 全链。
- **两张表都不进 `SyncFingerprint` 的 20 张表**：写 `quiz_runs` 必然同时写 `review_logs`，
  主要那三个数已经变了；而战绩页只是被看了一眼就落一行影子，为它多问一句「本机又动过」不值得。

### 2. 段位阶梯（`core.schedule.RankLadder`，纯函数）

- 数的是**已掌握**（间隔 ≥ `MASTERED_INTERVAL_DAYS = 21` 天），不是学过的词——光读过一遍不算掌握，
  与战绩页那个「已掌握」是同一个数。
- 十档门槛 0 / 20 / 60 / 150 / 300 / 600 / 1000 / 1600 / 2400 / 3500（前面密、后面疏）。
- 称号名全在 strings.xml（`rank_white … rank_sage`），拼法在 UI：`LEVEL` 带「级」、`DUAN` 带「段」、
  `SUMMIT` 光一个名字。一个词都不认识也是白词，不是「没有段位」。

### 3. 巅峰分 = 把整段历史重放一遍（`PeakScoreReplay`，纯函数）

- Elo 味：起点 1200、K=24；「对手强度」由这次回忆的 FSRS 难度与到期间隔推出（间隔每 3 天 1 分、封顶 240 天），
  「困难」算半分——它是真实的回忆，只是费劲，当答错会凭空贬低一次。
- 界面给两个数：现在多少、历史最高多少。`samples < 20` 时**不叫它巅峰分**，只说「重放了 N 次记录」——
  二十条以内的曲线只是噪声。
- 只读 `review_logs` 里 `kind='recall'` 的那批：`attempt` 没动过卡片，也就没资格改分。

### 4. 宿敌与复仇：现推，不建表

- `Nemesis.wordIds(recallEvents)`：最后一次真记账是 AGAIN 的那些词，最近把你说倒的排最前。
  之后在任何入口真记账地认出来一次，它自己就从名单上下去。
- 第四个测验入口 `QuizMode.NEMESIS`（`QuizService.nemesisCandidates()` / `planNemesis()`）。
  这里**故意不加**「今天已经回忆过就不再考」的闸门：认出来一次它就下去了，还留在名单上的，
  就是今天也没打赢的那个。
- `quiz_session.mode` 本就是 TEXT，所以整件事没有 Room 迁移，中途退出照样原位续做。

### 5. 连对与破纪录：只说自己比过的

- `QuizState.streak / bestStreak` 只在计分那一路走：当堂重练不加，答错与「不确定」归零。
  两个数随 `quiz_session` 的 JSON 存成**带默认值的可选键**，旧存档照读，不动表结构。
- `asked` 只数计分的题，正确率里不混进不计分重练。
- 破纪录 = 同一个入口自己以前的 `MAX(correct)` 且必须严格超过；**一个入口的第一组永远不说破纪录**（没比过）。
  留底写完才知道这个，所以那一行晚一步出现；用户已经点去下一组就不再改他的界面。

### 6. 界面四条（同刀做完，不改任何口径）

- 今日页：热力图与趋势并成一张 `RecentCard`（13 条竖纸条 + 一条平滑线，`feature/home/HomeCharts.kt`）——
  两件事说的是同一批日子，不该上下各摆一张卡。
- 词库页：搜索框尾部一个相机图标＝主词源（截图 OCR），txt / PDF / 导出 / 易混词收成搜索框下面一行 chips；
  `WordRow` 去掉左边的色条、字号降一档、释义一行截断（`masteryPalette` → `masteryInk`），
  一排看过去的密度才对。
- 设置页改成折叠分区（`DisclosureSection`，一次只摊开一个，默认摊开「备份与同步」），同步置顶。
- 室友入口从一整张卡改成压在角落的一枚便签（`RoommateNote`：≤260dp、`rotate(-0.8f)`、一行、
  名字 · 最新一句 + 小鱼干数）。
- 用户提的「正文不要装进卡片」「点词弹窗不要加分隔线」——现实现的阅读正文本来就不在卡片里、
  词卡本来也没有分隔线，当次会话核对过，无需改动。

### 7. 字要少

段位怎么升、巅峰分怎么算、宿敌凭什么上名单，全部写在关于页那两节里；主界面只给数和一个按钮。

## 后果

- 战绩页第一次有了纵向：过去（巅峰分、以前最好的一天）、现在（此刻能想起、战斗力）、
  下一步（还差几个词升档、几个词欠你一次复仇）。仍然一个字都不写进调度。
- Room 到 18。升级只建两张空表，所以旧库第一次打开战绩页必然报「记录还少」，直到攒够 20 次真记账——这是有意的。
- 最近测验与影子快照不在血缘指纹里：换机恢复后成绩从当前这一组重新开始数。成绩是给人看的，不是账本。
- 门槛按考研词表（`ky` 4,799 词）的规模排：往上每一档都要真把一批词的间隔推远，
  词圣那一档基本是整本词库都走完，正常情况下要按月算。
- v3.7 与 v3.8 合并成一次构建交付（versionName 3.8.0 / versionCode 25），**没有逐刀真机验收**。
