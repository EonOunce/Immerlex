# 0029 界面重做：一个主角、两档主色、五格底栏、一张战绩（v3.7）

## 背景

用户 2026-11-09 提的界面问题，加上两轮情绪版反馈：

> 「底栏要不要做成中间是主页、左右各两项内容的形式，阅读要不要变成沉浸式」
> 第一轮情绪版：「我觉得你画的太板正了，没有那种灵活灵气感，配色太杂……他是有层次的，不是全部
> 平铺在页面，而且整体很圆润……他的有主次……**你的每个都是主**」
> 第二轮（暖阳杏黄 / 珊瑚橘两张）：「哇！！！这个太好了！！！两种我都挺喜欢，你可以做两种配色呀」
> 另：「分享卡那里它的字体对比度不够，太白了，看不清」

所以这一刀只改**呈现**，不改任何数据口径：一个页面只留一个主角，其余靠叠压、尺寸、
倾斜退到第二层；全部大圆角 / 胶囊 / 正圆，不加直角色条；配色定成两档够亮的暖色，
用户当场可切。

## 决定

1. **主色做成一档可选的东西，不是一种颜色**
   `enum class Accent` 声明在 `core/settings/AppPreferences.kt` 里（跟 `Appearance` 同一处）：
   两档 `WARM = #FFC94D`（暖阳杏黄）、`CORAL = #FF8A5C`（珊瑚橘），core 只存 ARGB 整数与 key 字符串
   （`accent`，SharedPreferences，跟着 `appearance` StateFlow 立即生效，**没有 Room 迁移**）。
   `Theme.kt` 里 `LightScheme/DarkScheme` 改成 `lightScheme(accent)/darkScheme(accent)`，
   并新出一个 `LocalAccent`（原始色值，给"铺满整块"的主角用，不从 `colorScheme` 绕）。
   因为它们本身偏亮，**反色一律用墨黑** `#201D1A` 而不是白色——压在亮黄亮橘上比白字清楚，
   也顺手过了对比度。认不出的存档值一律 `Accent.saneOr()` 退回默认。
   入口两处共用一个 `AccentSwatches`（两个圆点，选中那个描一圈墨边压一个勾）：
   今日页标题旁（一键换色）+ 设置页「阅读外观」里一行。
2. **底栏五格，主页在正中抬起**（`app/ui/AppBottomBar.kt`，替掉 `NavigationBar`）
   顺序按 `Destinations` 的声明顺序：词库、阅读、**今日**、战绩、设置。
   正中一格画成一枚压在胶囊上沿的主色正圆（`offset(-8.dp)` + `shadow`），其余四格图标 + 11sp 小字；
   整条是一个 29dp 圆角的浮起胶囊，不是贴底的平板。`goToTab` 因此从 `Destinations` 改成收 route 字符串。
   **顺带修掉一个老 bug**：原来 `goToTab` 带着 `saveState`/`restoreState`，切走再切回来会把离开时那个
   *浮层页*（比如从今日页卡片进舍友页）原地恢复——用户看到的是"我明明点了底栏，怎么还在舍友页里"。
   现在只 `popUpTo(findStartDestination())` + `launchSingleTop`，不再恢复保存的状态：
   点某一栏就回这一栏的首页，子页该重进就重进。测验与舍友的中途进度本来各自有库（`quiz_session`、
   室友表），所以这一点不丢任何东西。
3. **今日页只留一个主角**（`feature/home/HomeScreen.kt`，热力图与趋势拆到 `HomeCharts.kt`）
   - `HeroCard`：铺满主色的 30dp 大圆角块，只回答"今天到期几个词、从哪开始"——
     72sp 衬线黑体数字 + 一条墨色胶囊按钮（`开始今日阅读 →`）。
   - `StreakStamp`：连续天数做成 74dp 的**圆形印章**，`rotate(8f)`、往右上角压出去半截。
     它靠叠压成为第二层，而不是另起一张卡——这是那轮"你的每个都是主"的正面回答。
   - `SecondaryStack`：测验与提前复习压成一对各歪 1.4°、彼此咬住 14dp 的白卡，比主角小一圈、不铺色。
   - `RoommateNote`：室友是一条便签（`primaryContainer` 暖底、衬线、歪 0.8°），不是又一张标准卡。
   - 下面才是小字统计行、热力图、趋势、补卡那一句。原来自今日页的"今日到期 / 已完成 / 连续"
     三张等大卡片全部取消。
4. **新增一栏「战绩」**（`feature/stats/`，只读）
   口径全部在 `core/schedule/ScheduleService.retentionReport()` 里现算，**不新增表、不写库**：
   `canRecall` = 学过且此刻 FSRS 可提取概率 ≥ 0.9 的词数（用 `Scheduler.retrievability`，不自己写公式）；
   `mastered` = 间隔 ≥ 21 天的词数；`nemesis` = 失误次数最多的那个词（词面 + 释义 + 失误数）；
   `strength` = 只给人看的 0–100（`0.5 × 平均可提取概率 + 0.5 × 已掌握占比`），**不参与任何排期**。
   版面沿用今日页那套：主色大块 + 印章式第二层，`StatsShareCard.kt` 另出一张 1080×1440 的炫耀卡
   （走同一套 `FileProvider` + `ACTION_SEND`，只写 `cacheDir/share/`，不上传）。
   这一页回答的是用户那句「拿高分又怎么样呢，又不能炫耀的」。
5. **分享卡的字改深色**（`feature/home/ShareCard.kt`）
   海报背景恒为纸色 `#F5F4F0`，但深色主题下默认内容色接近白，于是整张卡白字压在纸上。
   补 `LocalContentColor provides ImmerlexColors.Ink`（一处盖住所有没写死颜色的字），
   次要标签统一换成更深的 `PosterMeta = #63677A`。**没有改卡片尺寸与版式**。

## 后果

- 主色只有两档、且都是暖色：`Icons.Filled.Star` 这类系统图标在亮黄底上的辨识度、
  以及杏黄当 `primary` 时链接类文字的对比度，都只在模拟器上看过，**待真机验收**。
- 底栏中间那一格抬起 8dp，点击热区比 Material 默认的 `NavigationBar` 小；模拟器上五个入口都点过，
  换栏后回到各栏首页（不再带回浮层页）。
- 「战绩」这一栏是第五个入口，但**不是**第五个底部栏之外的新页面——它就在底栏正中偏右一格。
  数字全部来自已有 `review_logs` + FSRS 卡片，不需要迁移，旧库直接能出报告。
- 这一刀没碰阅读页正文的三色口径，也没碰室友页（换新皮单独一次做）。
- 分享卡上那两张**词墙在当天一个词都没有时会留下一整条空白**（版面按两行墙预留）。这是 v2.5 就有的行为，
  这一刀只改了字色；但闸门上线后"今日回忆"更容易是 0，空白也就更容易看见。**没在这一刀里动版面**，
  留给真机看过的人决定要不要折叠那一段。
- 沉浸式阅读没在这一刀里（见 AGENTS「v1.5 剩余」旁的待办），因为它要动正文渲染与状态栏避让，
  和 ADR 0014 那条"嵌套 Scaffold 必须传 `RootHandledInsets`"的坑纠缠在一起。
