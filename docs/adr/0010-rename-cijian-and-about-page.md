# 0010 应用更名「词间」与规则页

## 背景

包名、数据库名、WebDAV 文件夹名都叫 Immerlex，但中文用户看不到这层内部命名，桌面图标下却直接露出英文名。同时今日页、阅读页、设置页堆了越来越多解释性文字（打卡规则、热力图口径、评分上限、备份内容），把操作本身挤到下面。用户 2026-10-29 定名「词间」，副标题「词在故事之间」，并要求把这些说明收进关于页。

## 决定

- 仅改用户可见名称：`app_name = 词间`，副标题 `词在故事之间` 只在关于页展示。`applicationId`、包名、数据库文件名、WebDAV 目录 `Immerlex` 全部保持原样——改名会让已装应用无法覆盖升级、旧备份失联，收益只有内部整洁。
- 设置页底部给一个「关于与规则」入口，独立页 `feature/settings/AboutScreen.kt` 按主题列出打卡、今日页、阅读与评分、提醒、备份、故事档案、书架与短篇、词库的完整规则。关于页显示版本号（`BuildConfig.VERSION_NAME`）。
- 主界面只留操作必需的一句话：今日页删掉整段打卡说明；热力图副标题只留「近 13 周 · 今天 N 个」；趋势副标题只留「学习词数」；新词行只留「新词 N 个」；阅读页删掉复习提示与三种评分状态提示；设置里删掉提醒规则、自动备份说明的长句；书架、短篇、故事档案的重掷提示同样移走。
- 云端备份目录名与提示里出现的 `Immerlex` 保留（它是真实目录名），关于页说明「沿用旧名」。

## 后果

- 桌面显示中文名，用户仍能覆盖安装旧版本；旧备份不需要迁移。
- 规则说明有唯一归宿，以后加规则只改 `strings.xml` 的 `about_*` 与 AboutScreen；主界面不再重复解释。
- 评分状态（重学/改判/未到期）不再在词卡上提示，用户需要从关于页了解，这是有意的取舍：词卡只保留操作。
