# 0013 嵌词排版、书架重做与短篇自由度

日期：2026-10-29

## 背景

用户真机截图指出六处问题：学习模式词与释义之间偶有空格；复习模式词与括号之间有空格、
且括号本身是多余的；除今日页外五个页面标题与状态栏之间间距过大；短篇只有三个预设腔调，
自由度太低；书架太简陋；应用图标不好看。

## 决定

1. **嵌词排版**（`feature/reader/ReaderText.kt`）：学习模式渲染成 `word（释义）`，全角
   括号紧贴单词、中间**不留 ASCII 空格**，括号与释义一起刷上高亮底色。原先那个空格既是
   换行点（释义会被甩到下一行），又被刷进高亮块，看着就是"有时候有空格"。复习模式**不再
   画 `（　）` 占位**，只画单词：判断发生在点开之前，空括号是噪声。`ReaderTextTest` 锁住
   两种模式的字符序列。
2. **状态栏双重避让**：根 `ImmerlexRoot` 的 `Scaffold` 已经吃掉状态栏内边距，嵌套的
   `Scaffold` 再吃一次就多出约一个状态栏的高度。统一用 `app/ui/RootHandledInsets`
   （= `WindowInsets(0,0,0,0)`）传给嵌套 Scaffold；M3 `TopAppBar` 有自己的 `windowInsets`
   参数，也要一并传。今日页当时没有嵌套 Scaffold，所以只有它是对的。
3. **短篇自由度**：Room v8 给 `chapters` 加 `toneText` 与 `idea` 两列（`NOT NULL DEFAULT ''`，
   连载章节用不到，保持空串）。写短篇时可选填「这篇想写什么？」和「自己定腔调」——腔调
   chip 是三个预设 + 一个"自己定"，选"自己定"才出现第二个输入框，此时 `genre` 存
   `CUSTOM_TONE`、原话存 `toneText`。两句话跟着这一篇落库，`rewrite()` 原样喂回模型，
   所以重写短篇不会换腔调、不会换词。`ShortPlan` 是这三格的唯一载体。
4. **书架**：从阅读页底部的半屏 sheet 改成整页 `ShelfPage`。**不画假书脊或封面长条**
   （用户明确否掉"像阅读 app 那样摆个长方形"）。呈现是：顶部一张"正在读"大卡（腔调 /
   标题 / 连载或短篇 / 继续读），下面「连载」和「短篇」两组 1:1 色块卡。色块颜色由题材名
   哈希出的**固定色相**决定（`shelfHue`，返回 0–359 **度**，`Color.hsl` 要的就是度数），
   同一本书永远同一个色。短篇支持长按多选删除；删正文不动词库与复习进度。不设百分比进度条。
5. **应用图标**：前景就是应用名的第一个字——思源宋体 Heavy（OFL 授权）的「词」，按墨迹
   包围盒居中、em 46dp，最远一角离圆心 30.6，落在 108dp 视口的 66dp 安全圆内。轮廓由
   `scratch/icon/make_foreground.py`（fontTools，未入库，需要重做时按此重写）从字体里抠成
   `pathData`（TrueType 二次曲线折成三次贝塞尔；`fillType="evenOdd"`，否则「口」「司」的
   封闭腔体会被涂实）。**前两版试过横条
   组合**（"三行正文 + 中间一行被一个词顶起来"），在 48dp 下全部读成"列表里多了一个色块"，
   最后退化成汉堡菜单；铁锈橙也一并否掉。结论：小尺寸下唯一还站得住的是单个汉字。不画书脊
   也不画封面——这个应用的对象是"词在句子里"，不是"一本书"。`<monochrome>` 层同一个字形、
   全白，供 Android 13 主题图标使用。

## 后果

- 复习模式行内不再有任何占位符，词与前后中文之间靠字形自身边距隔开；用户要释义就点词。
- 短篇的两句话是**可选**的：都不填时 prompt 写"写什么由你定"，行为与 v1.1 的三预设一致，
  旧数据（`toneText` / `idea` 为空）不需要回填。
- `shelfHue` 依赖 `String.hashCode()`，它对同一字符串稳定，因此色相在跨版本、跨设备上都
  一致；但它不是设计过的配色表，题材很多时会出现相邻色相接近的书——可接受，因为卡片上
  始终写着题材名，颜色只是找回它的线索。
- 书架页占满整屏，阅读页原来的"关掉 sheet 继续读"变成"按返回或右上 × 回到本章"。
- 图标只换前景与单色层，背景色从 `#BC4B12` 改成纸色 `#F5F4F0`（与 app 内的 `Paper` 同值），
  字形用掌握色竹青 `#2F7D4F`；包名与 `applicationId` 不变，覆盖升级后桌面图标会刷新但
  快捷方式不会失效。
