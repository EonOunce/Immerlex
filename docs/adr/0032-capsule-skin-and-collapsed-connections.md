# 0032 胶囊皮统一到词库 / 阅读 / 设置，接口配过就收纳（v3.9 候选）

## 背景

v3.7 / v3.8 把今日页重排成"主卡 + 小卡"，用户 2026-11-11 看完说：

> 「主页改得挺好的，不用变了，但是你词库、阅读和设置还是没改成你给我展现出的胶囊的形式啊。
> 像同步、ai接口这些接口类的就不用一直展示出来，你设置过一遍就收纳就行了，又不是很常用的东西。你先和我讨论」

核对代码后，这句话一半成立一半不成立，两半都要说清：

- **折叠已经有了**（v3.8 的 `DisclosureSection`），但它是**裸行**——没有卡、没有投影、没有圆角，
  摘要还压在标题下面第二行。所以"看起来没改"是真的：同一页上今日页是胶囊、设置页是列表。
- **"一直展示出来"也是真的**：`BackupSection` 无论配没配过，都把网盘地址 / 账号 / 应用密码 / 设备名
  四个输入框连同说明文字全摊开，一屏十行；`AiSection` 同理。默认摊开的又正好是这一节。

讨论时给了四张对照图（`v39-capsules.html`）并问了四个经验层面的问题，用户的四个回答就是这一刀的规格：

1. 阅读正文**不装卡**，保持现在这样（与他早前那句「正文不要装进卡片」一致，样例图里那张纸色卡被否掉）；
2. 同步 / AI 接口配过之后**只留状态 + 两个动作**，账号密码网址收进「连接设置 ›」；
3. 进设置页**默认仍展开「同步与备份」**（否掉了"全部收起"的建议）；
4. 词库添加按钮**保留右下角浮动圆按钮**（否掉了"标题旁圆＋"的建议）。

## 决定

### 1. 一张皮，四处共用：`app/ui/Capsule.kt`

`Modifier.capsule(radius, elevation, color)` = `shadow` + `clip` + `background`，默认 22dp / 3dp /
`surfaceContainer`。同文件另有 `RoundKey`（顶栏圆键）、`PillSegmented`（互斥档位）、`PillChip`（可点胶囊）。

两条颜色上的取舍：

- **卡面用 `surfaceContainer`，不用 `surfaceContainerLowest`**。后者浅色下是纯白、深色下是 `#141310`，
  比页面底色还暗——深色主题里卡会"陷下去"而不是浮起来。`surfaceContainer` 两套都比页面亮一档。
- **分段与 chip 的选中态用 `inverseSurface` / `inverseOnSurface`（墨底反色字），不用主色**。
  主色两档都是亮暖色，压不住白字；`inverseSurface` 深色下自动翻成亮底，选中项在两套主题里都最抢眼。

今日页与战绩页原有的 4 处 `shadow + clip + background` 三行换成 `.capsule()`，**渲染逐像素不变**——
用户说了主页不用变，这一刀只把重复抽走（AGENTS 的"第三次复制必须抽象"）。

### 2. 词库页

- 搜索是一条整圆胶囊：放大镜 + `BasicTextField`（占位字坐在里面）+ 尾巴上一颗 40dp 主色 24% 圆，
  里面是相机图标＝截图 OCR 主入口。
- txt / PDF / 导出 / 易混词四颗 `PillChip` 排在搜索下面一行 `FlowRow`。
- 单词行是 18dp 胶囊：左边 9dp 掌握度点、词与释义、右边掌握度牌子（同色底）+ 到期日。
  到期日只摆 `MM-dd`，跨年才带年份（`formatDue`）——一列全是 `03-05` 时看不出是哪一年。
- 添加仍是右下角 `FloatingActionButton`，只是换成主色实心圆。

### 3. 阅读页：正文不装卡，边界只留在顶栏

顶栏单独成 `ReaderHeader.kt`：左 `RoundKey ☰`（本章目录）、中间宋体标题 + 书名小字、右 `RoundKey ⋯`；
下面一条进度 + 「只留英文」chip；再下面 `PillSegmented` 学习 / 复习。

- 平板上目录已经成栏，左边那颗圆键换成同宽 `Spacer`，标题才不会偏。
- **书架从常显按钮挪进 ⋯ 菜单**，和写下一章 / 重写本章 / 删除本章在一起。代价是书架多一次点击，
  换来的是顶栏从五个控件降到两个。
- 标题不再兼作目录入口（v3.0 起平板上就不是了，这一刀把手机也统一）。
- 正文、词卡、只留英文、点词命中、键盘、平板分栏一律没动。

### 4. 设置页：胶囊分区 + 接口配过就收纳

`DisclosureSection` 改成 20dp 胶囊：**单行头**（7dp 点 → 标题 → 右对齐摘要 → 折叠箭头），
摊开时一条 `HorizontalDivider` 再是控件。摘要从"标题下面第二行"挪到"标题右边半行"，
所以折起来的一节只占一行高。新增 `alert` 参数：那颗点平时是 `outlineVariant`，
**没配好或上次失败时变成主色**——不用读字就知道哪一节要管。

`SettingsState` 加两个判据，**都只认保存进本机的那一份，不认页面上的草稿**：

- `backupConfigured = backupAccount.isNotBlank() && backupPasswordSaved`
  （**网盘地址是预填的，不能当信号**；密码保存后才置位）；
- `aiConfigured = aiConfigSaved`（`load()` 时按 prefs 的网址 / 模型 + 密钥库里有没有 key 算）。
  第一版曾直接读三个草稿字段，验收时发现：填到最后一格表单就收起来，**保存按钮跟着消失**，
  不点「连接设置」就永远存不进去——所以判据改成只在保存后翻真。

配过之后：

| 这一节 | 只剩 |
|---|---|
| 备份与同步 | 上次上传那一行 + 「上传到网盘」「从网盘取回」+ 每日自动上传开关 + 「连接设置 ›」 |
| AI 接口 | 「正在用 <模型名>」+ 「测试连接」+ 「连接设置 ›」 |

点「连接设置」摊开原来那张表，改完点「收起」。**没配过的机器仍然直接是整张表**，
第一次配置的路径一步没变；填完保存的那一刻判据翻真，自动收成紧凑版。

`SegmentedRow`（Button / OutlinedButton 拼的档位）删掉，密度与提前复习组数都改用 `PillSegmented`。
「关于与规则」从 `OutlinedButton` 改成 `NavSection`（胶囊 + 右箭头），词库概况也是胶囊。

**分区顺序与默认摊开的那一节都没动**：用户明确选了"默认展开同步与备份"，
而这一节现在只有四行高，不再需要靠挪位置来省屏幕。

### 5. 没有 Room 迁移

全部是呈现层与两个内存判据；表结构、`SyncFingerprint`、备份格式一个字节没动。

## 后果

- 四页现在是同一套圆角、投影与卡面；深色下卡仍然浮起来，选中档位仍然最抢眼。
- 设置页折起来时一屏能看完八节；配过的两个接口节各只剩四行 / 两行。
- 代价一：书架多一次点击（进 ⋯ 菜单）。代价二：改网盘账号要先点「连接设置」。
- 关于页跟着改：新增「关于设置页」一段（折叠怎么读、那颗点什么意思、连接设置在哪），
  「关于阅读与评分」里"点章节标题换章"改成左上角圆键与右上角 ⋯，
  「关于备份与恢复」补一句配过之后只剩什么。`backup_never` 去掉"填好上面几项"——那张表可能已经收起来了。
- 顺手把两个越过 400 行红线的文件拆开：`WordBankScreen.kt` 451 → 310（行与搜索胶囊去 `WordBankRows.kt`）、
  `SettingsViewModel.kt` 417 → 345（`SettingsState` / `PendingRestore` 去 `SettingsState.kt`）。
- **未做**：沉浸式阅读、室友页换新皮、Prompt V4；这三件仍按原议另刀。
