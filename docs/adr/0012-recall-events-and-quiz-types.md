# 0012 统一 recall 事件与独立测验题型

日期：2026-10-29

## 背景

旧计分规则（ADR 0004）是"到期打分算一次复习，同日同词封顶 2 条，
第 3 次起改写最后一条"。它解决了"手滑连点多算"，但和独立测验冲突：

- 同一个词在阅读、测验、提前复习里各回忆一次，本应各记一次、按实际间隔连续
  更新排期，旧规则却按入口决定记不记、谁覆盖谁；
- 学习模式看释义、打开词卡查意思、看完答案再点"认识"，这些都不是独立回忆，
  旧规则却把它们和"先回忆再反馈"混在一起；
- 改评分会把"多学一次"伪装成"没学"，用户无法理解，也没法从记录里还原
  真实的学习过程。

用户 2026-10-29 定的口径：**每完成一次"先回忆、再反馈"就记一次，交给同一个
FSRS 连续更新；看释义、查词、答错后的当堂重练都不记。** 阅读、测验、提前复习
不再有三套记账规则。

## 决定

1. **事件只有两种**，写在 `review_logs.kind`：
   - `learn`：第一次接触一个词、答案可见时写下。它只负责初始化 FSRS、把词送进
     排期，不算回忆成功；之后同一个词不再写 learn。
   - `recall`：答案先藏住、用户先作答再看到反馈。阅读复习模式、测验、提前复习
     都走这一种，各记一条。`review_logs.questionType` 记题型（阅读为 null），
     旧行迁移后默认 `recall` + null，不丢数据。
2. **没有每日次数上限，也不再改写旧评分。** 每次 recall 都按当时的卡片状态
   连续计算；同一秒内的多次 recall 按记录时间 + 行号定先后。手滑只在阅读页
   评分后给一个几秒的撤销窗口（删掉最后一条并恢复评分前快照），窗口过后就是
   真实记录。
3. **学期只决定"怎么考"，不决定"什么时候考"。** 每个词仍然只有一张 FSRS 卡，
   没有分题型的到期日。题型由 `core.quiz` 的纯策略决定：
   - 门禁：新词只开英→中 + 挖空；有过一次成功回忆后加中→英；中→英成功过后
     加英文释义选词；易错词一开始就四种都可考。最近一次 recall 答错时，这个词
     先退回英→中/挖空，答对后再逐步放开。
   - 选择：在可用题型里挑"历史成功率最低 + 最久没问"的一种；刚答错的题型本轮
     避开；同分用会话种子打散，避免总问同一种。
   - 一次答对不会把题型锁死：成功率用 `(成功 + 1) / (尝试 + 2)` 平滑，继续抽到
     薄弱题型；答错会让薄弱度上升并触发降级。
4. **独立测验**只考今天到期或今天在阅读里学过的词，不考没见过的生词。答错词在
   本轮末尾用另一种题型再练一遍，**这次练习不写记录、不影响排期**。提前复习每次
   取当天碰过、还没到期的 5 个最不稳定的词，照常记 recall；完成一组后可"再来
   一组"，没有每日上限。
5. **统计口径**：打卡、热力图、趋势把 learn 与 recall 都算作"今天碰过这个词"
   （同词当天仍只算一个）；"已回忆次数"与题型强度只算 recall。旧 ADR 0004 的
   "同日封顶 2 条 / 改评分"被本 ADR 取代，其余"章是阅读单位、词是调度单位"
   不变。
6. **扩展契约**：新增题型只需在 `QuizType` 里登记一个 `tier`（基础 / 成功回忆后 /
   中→英成功后），加一个 `QuestionBuilder`（负责"需要什么数据、出什么题"），
   再补 UI 文案。门禁、薄弱度、换题型、提前复习都由策略自动生效，不碰 FSRS、
   不碰记账。
7. **复习模式里未到期的词只听"没想起来"**（用户 2026-10-29 补充，同一天的验收反馈）：
   复习模式下释义是藏着的，用户点开的动作本身就是要去核对"点开之前我认不认识"，
   所以这一眼的判断是合法的自评，只是它发生在到期日之前。于是 `WordAccess` 增加
   `Early`：卡上只给两个同权重按钮——「没想起来」按 `recall` + `AGAIN` 记一条
   （走测验提前复习同一条 `allowEarly` 路径，几秒内同样可撤销），「想起来了」
   **什么都不记**，因为提前记一次成功会把间隔推远，正是这套记账要避免的虚高。
   学习模式仍然是 `ViewOnly`：那里释义一直摊在正文里，"点开之前"不存在。

## 后果

- 同一天反复回忆会真实影响排期；FSRS-6 只区分"同一天"和"整天"，分钟级差异
  不计，这是算法粒度，不另造规则补救。
- 学习模式不再提供评分按钮（第一次 learn 除外）：答案已经看见了，再打分不是
  回忆。想计分请切复习模式或做测验。按 2026-10-29 定的"界面上不写说明书"，
  这类口径只写在关于页，词卡只留按钮本身。
- 撤销只覆盖阅读页最后一条，测验答案提交后不可改；要重来就再做一组，记录会
  按真实表现继续累积。
- 旧数据的 learn 事件不存在，迁移后老词按"已有历史"处理，不会重新走第一次
  学习；老记录没有评前快照，因此不可撤销。
- 题型强度是派生数据，不建统计表；换题库、删章只影响之后能不能出某类题。
