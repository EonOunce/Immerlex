# 0027 提前复习范围 / 自定义键盘 / 素材导入报数（v3.5）

## 背景

用户 2026-11-02 真机第三轮用完提了四条（原文见下），其中两条是产品问题、两条是新功能：

1. 50 片素材包能不能合成一份；以后自己加词，怎么知道哪些词已经在了。
2. 开始测验的地方没看到"几个词要请求 API"。
3. 提前复习在没背的时候总是 0 个可练——提前复习应该能复习之前学过的，不一定非是当天的。
4. 阅读页想要方向键选词（上 / 下一个词、空格开词卡、数字 1–4 从熟练到不认识），
   测验页想要 1–4 选 ABCD、答完按右键下一题；或者干脆让用户自己定义按键。

用户的四个取舍（逐个问过，以下是他自己选的）：

- **素材包不合并**：「不管了吧，反正现在能自动导入」——改为把"新增了几个词、更新了几个词"
  报出来，让用户看得出这一份和库里有没有重叠。
- **提前复习取"所有学过、没到期的词"**，不再限定当天的。
- **数字键 1 = 简单，4 = 忘了**：与 FSRS 自己的编号方向相反，就按他说的排。
- **自定义键位现在就做**，不留到以后。

第 2 条不是 bug：素材账（ADR 0025）在出题准备时本来就会报，只是素材全在库里时
`toAsk == 0`、准备瞬间结束，那句话一闪而过；已导入整包素材的设备绝大多数时候
**根本不会请求模型**，所以要说明的是这件事，而不是再加一行字。

## 决定

1. **素材导入报"新增 / 更新"两个数**（不再加合并功能）
   （`core/material/MaterialRepository.kt`、`core/material/MaterialSync.kt`）：
   - 导入前先按小写词面查一遍这一份里哪些词已经在库（`wordSurface`，全项目唯一归一化处）；
     已经开始算的 `written` 减去其中已在库的，就是 `added`，剩下的 `updated = written - added`。
   - `ImportOutcome.Imported(written, added, dropped, badCollocations)`；
     取包链路跨片累加，`MaterialSyncOutcome.Fetched` 也带 `packs / words / added / updated`。
   - 界面只说三个数：`新增 N 词，更新 M 词` / `没有新词，更新 M 词` / `没有新词，素材已是最新`
     ——用户自己加词时问的就是"怎么知道哪些是重复的"，这三个数直接回答。
   - 合并在任何地方都不做：素材表按词面主键，几十份包和一份包在库里长得一样，
     自动导入会一片一片补齐，没有必要先合成大文件。
   - 另加一份**词面清单**出口（`core/material/MaterialWords.kt` 的 `wordListOf`、
     `MaterialRepository.exportWords()`、设置页「导出词面清单」）：`text/plain` 的 txt，
     一行一个词、按字母序、去重。用途是"请别处的模型再出一批包"——把清单和
     "只给清单以外的词出包"一起发过去，就不会重复生成，也就不会把现有素材盖掉
     （重复的词导入时按词面覆盖它写了的字段）。导入后 `更新 = 0` 是可自证的判据，
     不必相信模型自己说"已排除"。整包 JSON（4,699 条约 1.6MB）不适合直接贴给对话模型，
     所以单开这一个只含词面的入口。

2. **提前复习取所有学过、未到期的词**（`QuizService.earlyCandidates`）：
   - 取数改成 `WordDao.learnedNotDue(nowSec, limit)`：`stability IS NOT NULL`
     （有过排期 = 学过）且 `dueEpochSec > now`，按到期时间从近到远、同到期按 id，
     `EARLY_SCAN = 60` 先捞一屏。
   - 排除**今天已经回忆过**的词（`recalledWordIdsSince(boundary.startOf(now))`，
     与"今天"同一个 `DayBoundary`）——今天考过的不该立刻再考；昨天之前学过的都算。
   - 一组仍是 5 个（`EARLY_GROUP_SIZE`）。今日页入口的数字是这一组能练几个
     （`coerceAtMost(EARLY_GROUP_SIZE)`），不是学过的词总数。
   - 「再来一组」的排除名单照旧：新词不够时允许拿刚练过的补上，所以练到最后不会空转。
   - 记账不变：每一次都是 `recall`；复习模式里"还没到期"的规则不受影响。

3. **键盘绑定模型**（`core/settings/KeyBindings.kt`）：
   - `KeyContext { READER, QUIZ }`：同一个键在两个场景可以各干各的事。
   - `KeyAction(context, defaultKeyCode)`，13 个动作：阅读页 上一个词 / 下一个词 / 打开词卡 /
     简单 / 记得 / 困难 / 忘了；测验页 A / B / C / D / 不确定 / 下一题。
   - 默认键位就是用户说的那套：阅读页 `↑ ↓ Space 1 2 3 4`（1 简单 → 4 忘了），
     测验页 `1 2 3 4` = A–D、`0` = 不确定、`→` = 下一题。
   - `KeyMap` 是**绑一次就完整的一份**：改绑到别的动作正用着的键时两个动作互换，
     同一个场景里不会出现两个动作抢一个键；不同场景互不影响。
   - 存一条字符串（`READER_EASY=22;...`）进 SharedPreferences（非密钥设置，
     与字号、深色同一套），坏名字、坏数字、非正数一律跳过退回默认——
     一份坏设置不该让键盘失灵。`AppPreferences.keyBindings` 是 StateFlow，改完立即生效。

4. **自定义键位页**（`feature/settings/KeyboardScreen.kt`）：
   - 设置页「阅读外观」下面一行「键盘快捷键」进入；两端动作各列一屏，点一行进"按键"状态，
     按下一个键就绑上，按返回取消。音量键不接（系统音量要留着）。
   - 「恢复默认」清掉这条设置，全部回到默认键位。
   - 按键显示：空格 / 回车 / 退格 / 方向箭头用人话，其余用 `KEYCODE_` 去掉前缀的键名。

5. **阅读页键盘操作**（`feature/reader/`）：
   - `ReaderState.cursor` = 键盘停在正文第几个词（按正文里词出现的顺序）；没按过是空。
   - `↑ / ↓` 先收起词卡、再把光标移到上一个 / 下一个词；第一次按下落在第 0 个词上，
     到两端就停住（不绕回）。选中的词在正文里加下划线，颜色仍是橙 / 绿 / 蓝那一套。
   - 光标移动时如果目标词在屏幕外（或贴着边），正文自动滚过去；
     判断用 `TextLayoutResult` 的行位置，留 96px 边距，不整除做估算。
   - 空格打开 / 收起光标所在词的词卡；用手指点词也会把光标一并设到那一次出现的位置。
   - 数字键就是四档评分，走 `gradeFromKey`：学习/复习模式与点按钮完全一样；
     复习模式里未到期的词只有 `4`（忘了）记一次回忆，`1–3` 等同「想起来了」、不记账；
     学习模式的 ViewOnly 词不理会数字键。
   - 词卡抽屉是另一扇窗（`ModalBottomSheet`），页面级的按键接不到，所以抽屉自己包了一层
     `KeyCapture`；书架是同一扇窗里的整页浮层，它开着时阅读页的按键整体让路。

6. **测验页键盘操作**（`feature/quiz/QuizScreen.kt`）：
   - 只在 `QuizPhase.QUESTION` 且**这一题还没作答**时认 `1–4` 与 `0`；答完之后 `1–4`
     不再改选（选择不可改，与 UI 一致），`→` 才生效进入下一题。
   - `0` = 不确定，与点按钮同一条路径。

7. **键盘焦点**（`app/ui/Keyboard.kt`）：
   - `KeyCapture` 是唯一入口：请求焦点 + `onPreviewKeyEvent` 接 `KeyDown`。
   - 焦点会在换题、开关词卡、关书架后丢掉，所以 `requestOn` 带着这些状态重新请求；
     每次状态变化都重新抢一次焦点，不依赖系统把焦点还回来。

## 后果

- 键位存本机、不进备份：换机后要重新绑（与字号、深色同一类设备偏好）。
- `KeyMap.encode` 的格式（`名字=键码`，分号分隔）是私有的存储细节；改格式只需保证
  `decode` 能读旧串，不需要迁移。
- 提前复习的候选面从"今天碰过的词"扩到"所有学过未到期"，`EARLY_SCAN = 60` 只是为了
  别把整个词库一次读出来；`dueEpochSec` 上有索引，按到期扫描本身就是索引顺序。
- 素材导入的三个数字是"这一次写了几个词、其中几个是新词面"，不是"词库多了多少词"：
  素材包不会把词加进词库（ADR 0022），词库仍由用户自己加。
- 词面清单只列**本机素材表里的词面**，不是词库：素材挂词面（ADR 0022），
  所以两份清单口径不同，别混着用。
- 关于页补「关于键盘」一节；提前复习的说明从"当天碰过的 5 个"改成"所有学过、没到期的
  最近 5 个（今天回忆过的不算）"。
- 测试：`KeyMapTest`（默认键位、同键不同场景、改绑互换、跨场景隔离、存取往返、
  坏设置退回默认）、`ReaderKeyboardTest`（光标边界）、`ReaderTextTest`（下划线与
  点词落在第几次出现）、`QuizServiceTest`（提前复习取未到期词、排除今天回忆过的）。
  没有 Room 迁移。
