# 0031 释义逐字相同的两个词，不能互相当选项（v3.9 候选）

## 背景

用户 2026-11-11 在 v3.8.0 发出后提了一条：

> 「harbor 和 harbour 是词库两行，所以拼写变体有可能作为"同义"干扰项出现——这是 v1.3 就有的数据现象，要治得另开一刀」

词库按**词面**去重（`words.word` 唯一），而拼写变体（harbor/harbour、colour/color、who/whom）
是两行合法的词。ECDICT 对这几对的 `translation` **逐字节相同**，于是出题时：
英→中题（`Face.WORD`）的干扰项来自词库里别的词的 `translation`，
就会出现四个选项里两个中文意思一模一样，凭这个就能排除或者根本选不出唯一答案。

先量了一遍再动手：

- 77 片素材包 21,338 条干扰项里，与本词释义逐字相同的只有 2 条（0.01%）——素材包不是元凶；
- 73 组手写易混对（`ConfusableSuggestions`）里，没有任何一对的释义逐字相同；
- 真正会撞的是**词库随机池**（`randomWords(200)`，原来只滤了 `id != word.id`）。

## 决定

### 1. 判据是「释义逐字相同」，不是拼写距离

`core.word.SameGloss.same(a, b)`：两边 `trim` 后非空且完全相等。`harbour` 与 `harbor` 命中；
`four` 与 `for`（编辑距离 1）不该命中；`draft` 与 `draught`（释义确有差别）也不该命中。
没有用拼写距离做启发式——那是在猜意思。

### 2. 出题侧：两个选项不能共用一个中文面（`QuestionBuilders.optionsFor`）

`optionsFor` 现在对所有三种来源（易混词、素材包干扰项、词库随机池）统一走同一组过滤：

- 选项词面不得等于本词（原有）；
- 选项的**另一面**不得等于正确答案那一面（新增）：英→中看中文、中→英/挖空/释义选词看中文选项的
  `text`，靠 `Choice.zh(face)` 一处取；
- 已在选项里的中文面不再收第二遍（新增）：`fixedZh` / `distinctBy { it.zh(face) }`。

于是 harbor/harbour 同时在词库里、易混里挂着、或者 AI 素材里写了同义干扰项，都不会变成两个选项；
这不需要动任何数据。搭配题不受影响（它本来就按短语去重）。

`ConfusableSuggestions` **故意不改**：harbour ↔ harbor 是一条合理的「容易混」推荐，
用户点选后建立的易混关系本身没错，只是它不再能产出重复选项。

### 3. 导入侧：两个窗口，先说后做

导入计划拆成两步：`ImportRepository.prepare()` 只读不写，算出
`ImportPlan.words` 与 `SameGlossPair`（新增词 ← 同释义的已有词 / 同批新词）；
`ImportRepository.commit(plan, source, skipVariants)` 才落库。界面拿到计划后：

1. **第一窗「释义相同的词」**：逐条列 `新增 harbour（同 harbor）`，超过 6 条写「还有 N 组」。
   `跳过这些` 只导入每组里先来的那个；`都导入` 进第二窗；点外面 / 返回 = **整次导入取消**（不写库）。
2. **第二窗「两个都留着？」**：写清后果——「这 N 个词会和你已有的词分别排期；测验里不会再把它们互相当选项。」
   `确定导入` 才落库，`返回` 回第一窗。

两窗都走 `PendingImport(plan, source, confirming)` 这一份状态，词库页只摆对话框、不自己判。

导入结果提示多一个可选段：`解析 %1$d 条，新增 %2$d，重复 %3$d，缺释义 %4$d，跳过同义 %5$d`，
只在 `skippedVariants > 0` 时出现，其余三条文案一字不动。

### 4. 没有 Room 迁移

`SameGloss`、`ImportPlan`、选项过滤全是内存里的事；`review_logs` / `words` 表结构一个字节没动。

## 后果

- 拼写变体可以继续待在词库里，各自排期；测验里谁当正确答案，另一个就绝不会出现在选项里。
- 用户在导入时就被问一次，而不是做测验时才发现两个选项意思一样。
- 「跳过同义」是**默认推荐**：绝大多数情况下一对拼写变体只留一个就够；要留两个也有明确路径。
- 已有词库不需要清理；旧数据里的重复释义从此不再影响出题。
- 单测：`ImportRepositoryTest` 4 条（prepare 标记、新词之间也互比、跳过不落库、都留各写一行）、
  `QuestionBuildersTest` 2 条（拼写变体不当选项、两个同义干扰项合并成一个）。
