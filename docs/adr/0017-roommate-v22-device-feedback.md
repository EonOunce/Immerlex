# 0017 室友 v2.2：真机反馈的六条与测验素材落库

日期：2026-10-30。状态：已实现，模拟器验收（待真机）。前作见 [ADR 0016](0016-roommate-v21-daily-life-and-looping.md)。

## 背景

v2.1.0 预发布包第一次装在用户自己手机上（2026-10-30），反馈全部来自"真的在用"而不是清单：
建档时性格和台词是后台悄悄生成的，用户看不到也等不到；测验 48 个到期词卡在"正在准备题目"
一两分钟不动；阅读页三种颜色分不清"学过"和"今天该复习"；评分后的撤销 Snackbar 盖住正文底部、
每评一个词就排一条、还不说撤销的是哪个词；普通陪伴时表情出现得太少。另外小铺东西一多就把
舍友整个挡住，它送东西/收东西的话只落在小本子里，房间里看不见。用户要求这六条一次做完，
单独作为 v2.2 一刀验收，不与其他版本合并。

## 决定

1. **建档一次定好，等就等**。`rm_profile` 加 `setting`（用户多留的一句设定）与 `introLine`
   （Room v11，老室友两列留空、不补演）。建档走 `RoommatePersona`：先要第一句话、再要整本
   台词，两次调用都成功才落库——中途退出宁可显示"还没认识"，也不要一个没有台词本的房间。
   进度用 `RoommateSetupStage` 在界面上说出来，模型超时 25 秒；没配 key、超时、字段越界一律
   由本地句子顶上，建档一定会完成，区别只是等不等得到 AI。
2. **改名片只重发人设**。点房间标题上的名字进「它的名片」，改名字/三样底色/设定只重写第一句话
   和台词本；余额、账本、小本子、它送的东西、已买的礼物与菜谱一概不碰——它们不在 `RoommatePersona` 手里。
3. **礼物时刻上屏**。买下的东西与它主动送的礼物都返回一个 `RoomMoment(line, narration)`：
   它说的话进气泡，旁白落在房间下面的卡片；小铺开着时同一句旁白顶到"小铺"标题下面，
   因为房间的位置被 sheet 盖住了。没有旁白的那一段（摊货只有反应）就不显示卡，不编一句凑数。
4. **小铺限高**。sheet 强制一次摊开（`sheetState.expand()`），标题固定、下面的货只占 46% 屏高，
   舍友和气泡留在视线里。限高之后必须摊开——停在半展开会把货藏到屏幕底下，反而更难翻。
5. **测验：一组 20 题、进度可见、素材落库**。新增 `quiz_material`（Room v12，主键 wordId）：
   一个词的英文释义、例句、易混候选池只在第一次考它时向模型要一回，之后出题读这一行，
   不再每组重问一遍；易混选项按池子轮换，不总是同样三个。请求带真实超时，等待时分步报
   "正在请求 API""正在等待 AI 出题"——慢要看得见，卡住要能自己断。
6. **阅读页三色按阅读记录**。纯函数 `core.schedule.readerTone(word, ReaderMarks, nowSec)`：
   没学过=橙；在阅读里碰过=绿；今天到期且还没在阅读里回忆过=蓝，复习完立刻转绿。
   测验和提前复习不改色——只有阅读页自己记的 `learned` / `reviewedToday` 参与判断。
7. **撤销嵌进词卡**。评分后卡片照常立刻收起，撤销按钮挂在你接着点开的下一张词卡里，
   直到下一个词评分为止；本章最后一个词没有下一张卡可挂，就让它的卡多留 5 秒。
   不再有底部 Snackbar：它盖正文、会排队、且不说是哪个词。
8. **表情要常换**。每次互动换一张（跳过正在放的那张），房间开着时空闲 16 秒自己换一次
   （`idleAsset`，只在房间页计时，离开即停）。GIF 仍循环播放、连点不重启。
9. **易混词管理成页**（`feature/tricky`，词库页标题行进入）。组 = `tricky_links` 的连通分量，
   纯函数现算，不新增表、不迁移；可加词、移出（只断线、留标记）、删落单的词，或一行一组批量新增。

## 后果

- Room 升到 v12：`RoommateMigrationTest` 覆盖 v8→v9、v9→v10、v10→v11 与 v1→v11 全链，
  `QuizMaterialMigrationTest` 覆盖 v11→v12（含模型只答了一半时的默认值）；`quiz_material` 是纯缓存，
  删了只会多问一次 AI，不影响排期与计分。配色只认阅读来源由 `ReaderColourQueryTest` 在真库上锁住。
  一组 20 题的上限由 `QuizServiceTest` 在 JVM 里锁——真机与模拟器上的词库都凑不出 21 个到期词。
- 建档从"秒开"变成"可能要等二十几秒"，换来的是它一开口就带着用户给的那句设定；
  没网/没 key 时仍然立刻完成。
- 三色只认阅读来源，所以测验做完词不会变绿——这是刻意的：颜色回答的是"这篇里我读过它吗"。
- 撤销从全局 Snackbar 变成词卡内联，一次只能撤最近一个词；跨词的批量反悔本来就不被支持，
  少了一层状态。
- 室友的包按职责拆开：`RoommateService`（编排）/ `RoommatePersona`（人设）/ `RoommateDaily`
  （今天的一包）/ `RoommatePrompts`（四份 prompt）/ `RoommatePackSchema`（字段闸门）/
  `RoomBackdrop`（房间的画），仓库内不再有 >400 行的文件。
