# ADR-0007: 书架、阅读位置与短篇模式——章是阅读单位之后的第二刀

- 状态：已采用
- 日期：2026-10-29

## 背景

ADR-0004 把"章"定为阅读单位，但只解决了"能回看"，没有解决"书多了以后从哪继续"：题材（`genre`）一直兼任书的身份，阅读页却只认设置里的最后一个题材与它的最后一章。用户 2026-10-29 要求：阅读页有书架、记住上次看的那本与那一章，下次打开原样回来；同一天还要求 PDF 导入与今日页热力图，并把 v1.5 的第一项（短篇模式）提前实现。

短篇与连载的结构差异只有两点：短篇不按"第 N 章"编号，也不参与故事圣经的跨章连贯。它仍然是"中文正文 + 内嵌英文词 + 复习打分"，所以**复用章节 JSON 契约与校验器**，不为短篇另造一套正文格式。

## 决定

1. **书 = 题材，继续复用**。连载书不新增 `books` 表，书架按 `chapters.genre` 分组；这样生成、故事圣经、人物状态、今日页的题材语义一处都不用改。只有短篇是"篇"而不是"书"，单独列出。
2. **新增 `reading_positions` 表记"上次在看什么"**：`key` 主键，连载用 `book:<题材>`（一本一行，刚新建还没有章节时 `chapterId = 0`），短篇用 `short:<章 id>`；`updatedAtSec` 最大的一行就是下次打开的落点。不记滚动像素，只记书与章——重进本章从头读是可接受的，跳错书不可接受。
3. **`chapters.kind`（`serial` / `short`，默认 `serial`）**。连载查询一律加 `kind = 'serial'` 过滤，短篇有独立列表查询；短篇章号固定 0、`genre` 存腔调名（`EVERYMAN` / `LUSH` / `COLD`），不写故事档案、不改人物状态。
4. **短篇按词数定篇幅**：取今日队列前 15 个词，`词数 × 110` 汉字并夹在 1500–2500；校验底线 1200 字，不为一两百字再修一轮。腔调只做三段行为描述（小人物点题 / 情绪华丽 / 设定先行冷结尾），不复刻具体杂志样文。
5. **PDF 导入复用截图那条 ML Kit 中文识别通道**：`PdfRenderer` 逐页渲染（目标宽 1500px、最多 20 页），再交给 `OcrEngine.lines(bitmap)`。渲染位图**先铺白底**再画页——无底色 PDF 画在透明位图上，ML Kit 会把黑字当黑底，整页识别为空（已踩到并用 `PdfOcrTest` 锁住）。`PdfRenderer` 不保证线程安全，整个渲染循环钉在单线程 dispatcher 上。
6. **热力图按"当天不重复词数"计**，不是打分次数：同一天同一个词连点多次只算一个词，避免与 ADR-0004 的防刷规则互相拆台。13 周、周一为首列；配色用固定阈值 0 / 1–4 / 5–9 / 10–19 / 20+，不用相对分位——历史越长颜色含义越不能漂。
7. **Room 版本升到 5**：`ALTER TABLE chapters ADD COLUMN kind` + 新建 `reading_positions`；迁移测试 `BookshelfMigrationTest` 覆盖 v4→v5 与 v1 一路链到 v5。

## 后果

- 书架把"未写正文的新书"也保留在列表里（`chapterId = 0`），用户新建后关掉应用不会丢书；但一本从未写过章的书会占一行"还没写正文"。
- 短篇用 `genre` 存腔调名，与连载题材共用一列；所有按题材的查询都已加 `kind` 过滤，若新增查询忘记加会串数据——这是当前实现的已知代价。
- 短篇生成仍是真实 AI 调用，模拟器没有 key，因此本次只验证了 prompt 组装、校验、入库与界面（单测锁住），**真实短篇正文尚未生成过**。
- PDF 导入上限 20 页，超出会提示"只读了前 20 页"；扫描版 PDF 的 OCR 质量取决于页面清晰度，不做纠错。
- 热力图只回溯 13 周，更早的记录仍留在 `review_logs`，只是不画。

## 落地（2026-10-29，v1.1.0 / versionCode 6，模拟器验收）

- 书架与位置：`ReaderViewModel.rememberedChapter()` 取最新位置行，落在哪本就把 `prefs.genre` 跟着改；被删的章回退到该题材最后一章，整本没了回退到设置题材。模拟器实测：科幻 → 杀进程 → 重开仍是科幻；打开短篇后重开停在短篇。
- 短篇：`ChapterGenerator.generateShort(tone)` 走 `PromptBuilder.shortUser()`，`rewrite()` 对 `kind == short` 保持同一腔调与同一批词；`save()` 仅对连载调用 `recordChapterOutcome`。单测覆盖腔调文本、15 词上限、`kind` 入库、不回写人物状态、短篇重写保持 `kind`/腔调。
- PDF：模拟器用两份手写 PDF 实测，导入结果"解析 3 条，新增 3，重复 0，缺释义 0"；`PdfOcrTest` 4 项全过（两页进度回调、直接位图 OCR、PdfRenderer 出墨、文件缺失）。
- 热力图：`heatGridOf` 纯函数 + `HeatmapTest`；模拟器塞入 13 周复习记录后，今日页显示颜色梯度、连续 4 天与"今天 5 个"。
