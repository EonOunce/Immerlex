# ADR-0008: 趋势图、词库导出与"只留英文"

- 状态：已采用
- 日期：2026-10-29

## 背景

v1.2 收掉 v1.5 清单里的两项——今日页 30 天趋势图与 CSV/Anki 导出——并按用户 2026-10-29 的要求给阅读页加"只留英文"：把汉字全部隐藏、只留英文，但**位置不变**。这三件事都不改数据模型，难点在口径与呈现，而不在存储。

## 决定

1. **趋势与热力图共用一套口径**：都按"当天不重复词数"计，避免同一天反复点同一个词把柱子刷高（与 ADR-0004 的防刷规则一致）。窗口固定 30 天、含今天、未来记录忽略；无记录的日子计 0。纯函数 `core.schedule.trendSeriesOf`，数据仍来自 `review_logs`，**不新增统计表**，也不做后台聚合。窗口内最大值标在**纵轴顶端**（用户 2026-10-29 要求），标题下的说明只描述口径，不再塞数字。
2. **导出只做 CSV 两列 `word,translation`**：UTF-8、无表头、RFC 4180 转义（逗号/引号/换行）。Anki 桌面版可直接导入 CSV，不再维护 Anki 自有格式。导出走 SAF `CreateDocument("text/csv")`，**导出全量词库**，与当前搜索过滤无关；纯函数 `core.word.wordCsvOf` 只产字符串，文件读写留在 feature 层。
3. **"只留英文"用透明 span，不删字**：中文字符与释义槽都保留在 `AnnotatedString` 里，只把颜色画成透明。字符串内容与学习模式完全相同，所以换行、英文词坐标分毫不动；英文词保留掌握度高亮与点击标注，点词仍弹释义卡并可打分。开关不改 `ReaderMode`、不写库；复习模式的空白槽也一并透明。为了切换时版式完全稳定，**不额外加提示行**（提示行会把正文整体下推）。
4. **阅读页拆分**：正文渲染进 `ReaderText.kt`（AnnotatedString）与 `ReaderBody.kt`（正文/空态），`ReaderScreen.kt` 只做编排——加开关后阅读页一度到 419 行，触碰 400 行红线。
5. **短篇腔调 brief 补强**（研究副产品）：意林 = 具体小事 / 三句内进场景 / 小转折 / 动作或对话点题；花火 = 青春情感错过 / 贴身视角 / 具体物件 / 没说出的话收尾；科幻世界 = 一句话核心设定 / 事件中段切入 / 设定靠操作后果 / 冷处理反转。仍只描述写法，不复制杂志样文；也不存在可直接安装的"杂志写作 skill"，生成质量取决于模型本身。

## 后果

- 趋势只回溯 30 天，更早记录仍在 `review_logs` 只是不画；单日上限取窗口内最大值标在纵轴，窗口滑走会变。
- CSV 只有单词与释义，音标、例句、FSRS 进度不导出；导入 Anki 后是纯卡片，复习历史不迁移。需要完整备份仍用坚果云快照。
- "只留英文"下纯中文段落表现为空白行（位置被保留），整页看起来像填空纸；这是"位置不变"的直接代价。透明文字对屏幕阅读器仍可读（TalkBack 按文本读，不看颜色），作为自测视图可接受，若日后要求真正隐藏再补语义。
- 段内释义槽被透明保留，英文词之间会出现空白间隔；换来的是切换开关时英文位置严格不动。
- 切换开关不是持久设置，重进页面回到学习模式。

## 落地（2026-10-29，v1.2.0 / versionCode 7，模拟器自检）

- 趋势：`TrendTest` 4 项（30 格且含今天、同日去重、窗口外忽略、UTC→上海跨日）；模拟器带历史复习记录的库上柱状图正常渲染，纵轴顶端显示窗口最大值 12、底部 0，标题下的说明只保留"每天背过或复习过的词数"。
- 导出：`WordCsvTest` 3 项（两列与顺序、逗号/引号/换行转义、空释义）；模拟器经 SAF 存到 `/sdcard/Download/immerlex-words-20261029.csv`，15 行、含逗号的释义自动加引号，无表头。
- 只留英文：`ReaderTextTest` 6 项（学习/复习原文不变、可见字符只剩英文、透明 span 覆盖全部中文、标注仍可点）；模拟器上同一个四词短篇对照截图，`reluctant / ephemeral / lantern / ubiquitous` 与学习模式逐词同位，点词弹卡与打分正常。
