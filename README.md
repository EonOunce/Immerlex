# 词间 (Immerlex)

把要背的英文单词嵌进你正在读的中文小说里。词库自己攒（截图 / txt / CSV / PDF），排期交给 FSRS-6，
AI 按题材写中文章节并把「今天的新词 + 到期的词」织进正文，读完故事这一页，词就背过了一遍。
安卓应用，离线优先，不需要账号。

## 功能

- **词库**：微信/相册截图 OCR（模型打包在应用里，无 Google 服务也能离线识别）、txt、CSV、PDF 逐页识别；
  中文释义取内置的 ECDICT 精简库。词库永远是你自己按天加进去的，应用不替你批量导入。
- **排期**：FSRS-6（21 参数，与 py-fsrs 参考向量对齐）。一个词一张卡，到期词进今日队列。
- **写作**：OpenAI 兼容接口，baseURL / key / 模型名自己填。每章千字左右、嵌 20–30 词，密度三档（疏 / 中 / 密，默认中）。
  长篇有「故事档案」三层（设定条目 + 人物状态表 + 全书梗概）维持跨章连贯；短篇单篇自足，可选腔调或自己定调。
- **阅读**：学习模式（释义可见）与复习模式（释义隐藏，点了才揭示并打分）。正文一个词只有三种颜色——
  橙=没学过，绿=在这篇里碰过，蓝=今天到期还没在这篇里回忆过。支持「只留英文」自测视图、书架与阅读位置。接上键盘时 ↑/↓ 选词、空格开词卡、1–4 评分，键位可在设置页自己改。
- **测验**：五种题型（英→中、中→英、句子挖空、英文释义选词、搭配），一组 40 题，题型按这个词的掌握程度解锁；
  每个选项答完就地揭开另一面，答错或「不确定」在本组末尾换题型重练。中途退出，回来还在同一组的同一题。
  一个词的素材只向 AI 要一回，之后读本机存的那一份。键盘 1–4 选 A–D、0 不确定、→ 下一题。提前复习从所有学过、还没到期的词里取最近到期的一组，默认 5 个，可在设置页「测验」里选 5 / 10 / 20。
- **今日页**：今天到期几个、已完成几个、连续天数、13 周热力图、近 30 天趋势、每日到期提醒，
  以及一张可导出的每日报告分享卡（1080×1440 PNG，走系统分享，不上传）。
- **室友**（可完全忽略的一层陪伴）：学习换小鱼干，可以送礼、买它写的作品。钱和节奏由确定性程序管，模型只写文本。
- **备份与多设备**：坚果云 WebDAV。规则见下面第二节。

## 下载与安装

[Releases 页](https://github.com/EonOunce/Immerlex/releases/latest) 下载 `immerlex-arm64-v8a-release.apk`（真机用的那一份），
校验值在同 release 的 `SHA256SUMS.txt` 里。要求 Android 8.0（API 26）及以上。

手机上直接装：下载后打开，允许「安装未知应用」。或者连着数据线：

```
adb install -r immerlex-arm64-v8a-release.apk
```

只交付 arm64-v8a 这一份发布包；`x86_64` 那份只服务模拟器，不上架应用商店，也不出 universal APK。

## 素材包

测验里的英文释义、例句和搭配，可以在别处一次性生成一份「素材包」（JSON，一个词一行），装进应用就立刻能用。
装法有两条，互为退路：

1. **从 GitHub 取素材包**（设置页 →「出题素材」）。应用先读一份清单 `manifest.json`，再按清单一片一片下载，
   **每一片都要过 SHA-256 校验**才导入；对不上就停在那一片，已经进库的前几片照旧算数，再点一次接着补齐。
   清单地址默认指向最新 release，可以改成自己的镜像或本机服务器——分片按清单的相对地址找。
2. **导入素材包**（本机文件）。选一个本地 JSON 文件直接导入；这是网络取不动时的路，也是一切素材包的原始入口。

**现在有一份准备好的素材包**：清单在最新 release 上（应用里的默认地址就是它），77 片、7,161 条素材
（6,724 个词面）。前 50 片覆盖 ECDICT 考研标签词的 4,703/4,799——余下 96 个是最日常的高频词
（action、government 这类）；2026-11-02 追加的 27 片又补了 2,025 个常用词。日后加一片新分片、
清单追加一行就补上，已有分片不用重发。点「从 GitHub 取素材包」会一片一片取完；
取不动就用手上的 JSON 走第 2 条，两条路进的是同一个库。

想自己再补一批词，先点「导出词面清单」拿到一个 txt（一行一个词，就是本机已备过素材的全部词），
把它和「只给清单以外的词出包」一起发给别处的模型，就不会重复生成、也不会盖掉现有素材；
导入后报「新增 N 词，更新 M 词」，更新为 0 就是这批词一个都没碰旧的。

清单的格式：

```json
{
  "materialVersion": 1,
  "generatedAt": "2026-11-02T09:00:00Z",
  "license": "all-rights-reserved",
  "packs": [
    {"file": "material-pack-01.json", "words": 100, "sha256": "<这一片字节的 SHA-256>"},
    {"file": "material-pack-02.json", "words": 100, "sha256": "<...>"}
  ]
}
```

素材包的每一行：`word`（小写词面，多词短语也可以）、`definition`（英文释义）、`example`（例句）、
`exampleZh`（例句的中文）、`distractors`（易混候选：必须拼写相近、意思不同，别拿近义词凑）、
`collocations`（真实搭配：短语必须真的含有这个词）。一份文件是一个完整 JSON 数组，**每 100–200 词拆一片**。

素材挂在**词面**上，不挂在词库行上。所以先装素材、后加词，或者删了词再加回来，那个词都还认得自己的素材；
以后要扩词库，只要在清单的 `packs` 末尾追加一片新的分片、写清它的词数与校验值，不用重发已有分片。

重导一份改过的包只覆盖它写了的字段，没写的字段原样留着（填充式合并），导入是一个事务。

## 坚果云同步规则

- 备份里有词库、章节、复习进度、故事档案、素材与室友存档；**AI 接口的地址、密钥、模型名不在里面**，取回后要重填。
- 用法是「学完上传、学前下载」：这台机器学完点上传，换一台之前先取回最新那份。**上传永远安全**——
  文件名写着日期、时分秒、设备名和库版本，同一天再传也不会顶掉上一份。
- 取回之前会比对这台机器和上次同步时的样子：空机或已经一致就直接下，
  **有还没传上去的记录就先问一句**，并说清会丢多少词 / 章 / 记录，由你在「先上传」和「仍然下载」之间选。
- 覆盖本机库之前自动留当前库的快照，最多 3 份，取错了可以就地退回去；每一份取回前都要过校验，不过就一点不动本机数据。
- 云端保留最近 60 份，外加更早每个月最后一份。每日自动上传只是每天多传一份，有网络时才跑。
- 备份文件本身不加密，靠 HTTPS 传输；坚果云用「应用密码」，不是登录密码。

## 隐私

- 全程离线优先，没有账号体系，没有任何遥测、统计或广告 SDK。
- 截图与 PDF 的文字识别都在本机完成（ML Kit bundled 中文模型），不上传任何图片。
- 应用主动出网只有三种情形，全部由你决定用不用：
  把你配置的 AI 接口地址与本次文本发过去（写章节、出题补素材、展开故事档案）；
  向坚果云 WebDAV 上传与下载备份；以及从你填的清单地址**往下读**素材包文件。
- 从 GitHub 取素材包只是下载公开文件，不上传任何东西。
- API key 与坚果云应用密码只存在本机的加密存储（EncryptedSharedPreferences）里：不写日志、不进备份、界面上不回显。
- 不填 API key 也能完整使用：AI 缺失时静默降级到本地题库与本地文本，阅读、测验、备份、分享卡照常。

## 构建

环境：JDK 21、Android SDK（`compileSdk 35`，AGP 8.7.3）。仓库根目录执行：

```powershell
# 单元测试：FSRS 参考向量（纯 JVM 模块）+ 解析 / 导入 / 调度 / 渲染 / 同步等测试
$env:JAVA_HOME='D:\dev-tools\jdk-21.0.12.1+1'; .\gradlew :core:fsrs:test :app:testDebugUnitTest --no-daemon

# lint + debug 包（CI 跑的就是这四步，不跑模拟器测试）
$env:JAVA_HOME='D:\dev-tools\jdk-21.0.12.1+1'; .\gradlew :app:lintDebug :app:assembleDebug --no-daemon

# 发布包：需要 keystore.properties（不进版本库）指向签名用的 jks
$env:JAVA_HOME='D:\dev-tools\jdk-21.0.12.1+1'; .\gradlew :app:assembleRelease --no-daemon
# 产物：app\build\outputs\apk\release\immerlex-arm64-v8a-release.apk
```

没有 `keystore.properties` 时 release 任务会退回 debug 签名，仍能出包，但那份只该用来自己试，不该发出去。

Room 的迁移测试要连设备（模拟器或真机），跑之前先确认只有一台设备在线——它会往**所有**在线设备装包并清数据：

```powershell
$env:JAVA_HOME='D:\dev-tools\jdk-21.0.12.1+1'; .\gradlew :app:connectedDebugAndroidTest --no-daemon
```

代码结构：`core/*` 是能力（db / ai / fsrs / dict / ocr / schedule / quiz / material / backup / roommate / tricky），
`feature/*` 是界面，feature 之间不互相依赖；规则与决策写在 `AGENTS.md` 与 `docs/adr/`。
